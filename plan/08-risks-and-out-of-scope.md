# Risks, mitigations, out of scope

## Risks

| Risk | Mitigation |
| --- | --- |
| Hero project not publicly deployed | Strong GitHub README, architecture diagram, screenshots, optional short walkthrough video |
| “100+ shipped” reads inflated | Always pair with **cumulative across roles** framing (tooltip, footnote, or sublabel); replace placeholders when possible |
| Overlap of 2024 roles confuses recruiters | Honest dates + “part-time / concurrent” where true; avoid implying exclusive full-time |

## v1 out of scope

- Blog or CMS for long-form posts
- Testimonials section **without** real quotes (omit entirely)
- External API for philosophy quotes (use **local JSON** only)

## Optional later

- Testimonials (1–2) when available
- Stronger Tier A metrics in hero when measured
- v1.1+: second theme (only if maintaining cost is acceptable)
