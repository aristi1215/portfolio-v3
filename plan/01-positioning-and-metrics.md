# Positioning and metrics

## Audience and identity

- **Primary audience**: technical screeners + hiring managers at **early-stage startups**; “full-stack breadth,” ownership tone.
- **Banner**: **Full-stack engineer — React/TypeScript + Python (FastAPI) APIs + SQL**.

## Proof strategy

- **Do not** anchor credibility on Cloudflare Pages demos alone.
- **Lead with**: employer work + GitHub/case studies + engineering narrative.
- **Supporting demos** (A/B testing, AI QA): linked as **secondary** proof.

## Discipline / learning wedge (reframed for employers)

Sell **judgment + outcomes + reliability**:

- Predictable delivery (Scrum, PO communication)
- Maintainability mindset (Infera aligns)
- Growth trajectory (skills graph, honest “next” skills)

## Agreed hero metrics

| Metric | Value / rule |
| --- | --- |
| Years of experience | **2.5** (site + résumé + LinkedIn aligned) |
| Shipped items | **100+** cumulative across professional work (tickets, features, fixes—not one project). Optional sublabel: “Cumulative across roles and projects.” |
| Extra slots | **Placeholders** OK until replaced (e.g. p95 TBD) |

## Tier system (when replacing placeholders)

- **Tier A**: measured (latency, bytes, error rates).
- **Tier B**: substantiated proxies (tickets/PRs in a defined window).
- **Tier C**: narrative + artifacts (diagrams, screenshots)—no fake percentages.

Do not invent traffic or user counts without data.
